# FileDock Privacy

Effective: 2026-11-11

FileDock is a local macOS file manager.

- FileDock does not require an account.
- FileDock does not contain advertising, analytics, telemetry, or crash-reporting services.
- FileDock does not upload file contents, file names, paths, usage history, or personal information to a FileDock server.
- FileDock accesses local folders only to perform actions requested by the user and subject to macOS permissions.
- Google Drive integration only discovers and opens folders exposed locally by Google Drive for desktop. FileDock does not sign in to Google, call the Google Drive API, or operate Google Drive synchronization.
- Opening a folder in Terminal launches the macOS Terminal application at that local folder.

Future releases that add data collection or an online service will require an updated notice before those features are enabled.

## 한국어

FileDock은 Mac 안에서 동작하는 로컬 파일 탐색기입니다. 계정·광고·사용 통계·텔레메트리·크래시 전송 기능이 없으며, 파일 내용·이름·경로·사용 기록·개인정보를 FileDock 서버로 보내지 않습니다.

Google Drive 기능은 Google Drive 데스크톱 앱이 Mac에 제공한 로컬 폴더를 열기만 합니다. FileDock이 Google 계정에 로그인하거나 Drive API·동기화를 수행하지 않습니다.
